- **Interactive 3D WebGL:** Three.js, `@react-three/fiber`, `@react-three/drei`

- **Styling:** Vanilla CSS design tokens with Tailwind CSS (Dark editorial aesthetic)

## 📂 Verified Project Highlights

1. **Nagorik Sathi AI (CivicSync):** Municipal civic coordination platform featuring multimodal Bangla intake, server-side Haversine spatial verification ($\le 50\text{m}$ radius), and tamper-evident chained SHA-256 audit logging.
2. **AI Resume–Job Matcher:** In-memory PDF/DOCX document parsing, hybrid spaCy taxonomy extraction, and Sentence-Transformer (`all-MiniLM-L6-v2`) semantic embeddings.
3. **PneumoVision AI (Medical AI):** Deep learning chest radiograph screening using DenseNet121 and Grad-CAM (Gradient-weighted Class Activation Mapping) explainability overlays. *(Research & triage simulation only).*
4. **FitHub Management System:** Desktop facility management application in Python 3.13 (Tkinter) and MySQL 8 with bcrypt salted password hashing and automated Excel reports.
5. **NexaMart Retail System:** Full-stack multi-store POS management platform built with Next.js (App Router), Prisma ORM, and PostgreSQL.
6. **Agroclimatic ML Research:** Minimal-feature crop recommendation and SHAP explainability on Bangladesh agricultural datasets (AgrClimateBD & SPAS-Dataset-BD).
7. **Bangla Regional Dialect NER:** Dialectal tokenization and entity recognition pipeline exploring BanglaBERT and XLM-RoBERTa across regional Bangladeshi dialects.

## 🚀 Local Development Setup

### Prerequisites
- Node.js (v18.x or v20+)
- npm (v9+)

### Installation & Run
```bash
# Clone the repository
git clone https://github.com/Mushfik19/my_portfolio.git
cd my_portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build & Linting
```bash
# Check code style and linter rules
npm run lint

# Build optimized production bundle
npm run build

# Preview production build locally
npm run preview
```
